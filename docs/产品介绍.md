# 数据中心测试验证管理平台 · 产品介绍

> 智航万恒测试部 ｜ 2026-09

---

## 一、平台定位

面向数据中心测试验证团队的一体化数字工作台，覆盖**测试项目全生命周期**——从项目立项、人员组织、现场测试执行，到知识沉淀、AI 辅助、报告输出。目标是把测试团队的**经验、数据和精度**沉淀在平台里持续积累，让"越用越准、越用越快"成为可能。

## 二、功能模块总览

### 1. 测试项目管理
项目立项/里程碑/甘特图、历史项目归档、测试人员池、人员考勤（含调休审批）、测试管理制度库（分级查阅）。

### 2. AI 测试专家（RAG 知识问答）
基于自建测试知识库（26 本国标全文、三大厂规范、故障案例库、排障方法论等）的智能问答：
- **检索质量实测 91%**（hit@3，31 道真实考题验证）；
- 快速/深度双档（秒级 Flash / 深度思考+联网）；
- 支持采纳/纠错自学习——团队纠正过的答案沉淀入库，全员共享；
- 粒子球交互界面：知识核心、思考信号、流式回答。

### 3. 图纸路由（行业特色功能）
上传 DWG 图纸整包，自动完成：格式转换（ODA）→ 文字坐标提取 → **规则引擎捋路由**（变压器↔中压柜、低压模块、机房机柜路由、柴发并机）→ D7 风格 Excel 成品一键导出。
- **AI 复核二次确认**：预扫描缺失/乱码/推定/跨表不一致，AI 逐条校准并给证据；
- **人工修正闭环**：复核时直接填正确值，一次确认、同楼栋终身自动应用；
- **自学习库**：人工确认的映射/容量回写管线，越用越准；
- **黄金基准回归**：7# 楼人工确认产物为基准，规则改动必须零差异才能上线。

### 4. 资源配置工作台
14 页配置矩阵：人员/员工/补贴/外协/假负载（自动核算自有 vs 租赁）/仪器仪表（资源库匹配）/耗材/劳务（三种核算模式）/安全/部门库/资源库/已交付存档（密码锁）/汇总统计。支持 JSON 导入导出、多端云同步（乐观锁防覆盖）。

### 5. 测试报告审核
长文档错别字/术语规范 AI 审核（分段并行），规则词典 + AI 双引擎，学习纠错库持续积累。

### 6. 故障日志抓取（运维保障）
平台自身故障一键快照（后端日志/容器日志/执行器/宿主资源/图纸管线/数据库健康 8 源聚合）+ AI 解析（错误时间线/根因/处置建议）。**账号白名单管控**，仅授权人员可见。

### 7. 权限体系
管理者/编辑者/阅读者三级角色 × 模块矩阵（含手动授权），飞书一键登录 + 账密登录双通道。

## 三、技术架构

```
浏览器（React 18 + TypeScript + Ant Design 5 + Vite）
        │
Nginx 容器（静态资源 + /api 反代，180s 长连接支持 AI 流式）
        │
Express 后端容器（TypeScript，REST API + SSE 流式）
        │
PostgreSQL 16 + pgvector（业务数据 + 知识向量检索）
        │
宿主机执行器（systemd）：DWG→DXF→规则挖掘管线（Python，容器零依赖）
```

外部服务：智谱 GLM（问答/复核/解析）、MiniMax（报告审核）、飞书 OAuth——**均可用开关隔离，核心业务不依赖外网**。

## 五、部署形态

- **公网**：单台 4C4G 云服务器，Docker Compose 三容器 + 宿主机执行器；
- **内网**：同构部署，飞书登录与外部 AI 按网络策略自动降级，核心功能完整（详见《内网部署说明》）；
- 数据库支持全量 dump 迁移，公网 ↔ 内网数据可平滑搬迁。
