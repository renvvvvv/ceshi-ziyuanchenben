# 数据中心测试验证平台 — 服务器部署指南

## 一、架构概览

```
用户浏览器 → :80 (Nginx 前端)  ──┬── 静态文件 (React SPA)
                                  └── /api/ 反向代理 → :3001 (Node 后端)
                                                          │
                                                          └── PostgreSQL (Docker 内部网络)
```

| 组件 | 技术 | 端口 | 容器名 |
|------|------|------|--------|
| 前端 | React + Vite → Nginx 静态托管 | 80 (公网) | frontend |
| 后端 | Node.js + Express + TypeScript | 3001 (仅本机) | backend |
| 数据库 | PostgreSQL 16 | 5432 (仅本机) | postgres |

> 数据持久化：PostgreSQL 数据通过 Docker named volume `pg_data` 存储，`docker compose down` 不会删除数据。

---

## 二、服务器要求

- **操作系统**：Linux（推荐 Ubuntu 22.04 / CentOS 8+）
- **内存**：≥ 2GB
- **磁盘**：≥ 10GB
- **已安装**：Docker Engine + Docker Compose
- **开放端口**：80 (HTTP)

### 安装 Docker（如未安装）

```bash
# Ubuntu / Debian
curl -fsSL https://get.docker.com | sh
sudo systemctl enable --now docker

# 验证
docker --version
docker compose version
```

## 三、部署方式

### 方式 A：一键脚本部署（推荐）

前提：本地已配置到服务器的 SSH 免密登录。

```bash
# 1. 配置免密登录（首次）
ssh-copy-id root@你的服务器IP

# 2. 执行部署脚本
cd ceshi-ziyuanchenben
bash scripts/deploy.sh

# 自定义服务器信息
REMOTE_USER=root REMOTE_HOST=1.2.3.4 REMOTE_DIR=/opt/test-platform bash scripts/deploy.sh
```

脚本会自动完成：打包 → 上传 → Docker 构建 → 启动 → 健康检查。

### 方式 B：手动部署

```bash
# 1. 本地打包（排除 node_modules 等）
cd ceshi-ziyuanchenben
tar --exclude='node_modules' --exclude='dist' --exclude='.git' \
    --exclude='server/node_modules' --exclude='server/dist' \
    --exclude='server/data' --exclude='__pycache__' \
    -czf /tmp/deploy.tar.gz .

# 2. 上传到服务器
scp /tmp/deploy.tar.gz root@服务器IP:/root/

# 3. SSH 登录服务器
ssh root@服务器IP

# 4. 创建项目目录并解压
mkdir -p /root/test-platform && cd /root/test-platform
tar xzf /root/deploy.tar.gz
rm /root/deploy.tar.gz

# 5. 配置环境变量
cp .env.example .env
vi .env   # 修改 DB_PASSWORD

# 6. 构建并启动
docker compose up -d --build

# 7. 查看状态
docker compose ps
docker compose logs -f backend
```

### 方式 C：服务器上直接拉取 Git 仓库

```bash
ssh root@服务器IP
git clone <仓库地址> /root/test-platform
cd /root/test-platform
cp .env.example .env && vi .env
docker compose up -d --build
```

## 五、日常运维

### 查看日志

```bash
cd /root/test-platform

# 所有服务
docker compose logs -f

# 仅后端
docker compose logs -f backend

# 仅前端
docker compose logs -f frontend
```

### 重启服务

```bash
docker compose restart          # 重启全部
docker compose restart backend  # 仅重启后端
```

### 更新部署

```bash
# 方式 A：本地重新执行脚本
bash scripts/deploy.sh

# 方式 B：服务器上操作
cd /root/test-platform
docker compose down              # 停止（数据不丢）
# 上传/拉取新代码...
docker compose up -d --build     # 重建启动
```

### 备份数据库

```bash
cd /root/test-platform

# 导出
docker compose exec postgres pg_dump -U postgres test_platform > backup_$(date +%Y%m%d).sql

# 恢复
docker compose exec -T postgres psql -U postgres test_platform < backup_20260702.sql
```

### 清理重来（⚠️ 会删数据）

```bash
docker compose down -v   # -v 会删除 pg_data 数据卷！
docker compose up -d --build
```

## 六、常见问题

### Q: 访问页面空白 / 502

```bash
# 检查前端容器是否正常
docker compose ps frontend
docker compose logs frontend

# 检查后端是否正常
docker compose logs backend
```

### Q: 后端连不上数据库

```bash
# 进入后端容器检查
docker compose exec backend node -e "
  const pg = require('pg');
  const pool = new pg.Pool({host:'postgres',port:5432,database:'test_platform',user:'postgres',password:process.env.DB_PASSWORD});
  pool.query('SELECT 1').then(()=>{console.log('DB OK');process.exit(0)}).catch(e=>{console.error(e.message);process.exit(1)})
"
```

### Q: 端口 80 被占用

```bash
# 查看占用
sudo lsof -i:80
# 或修改 docker-compose.yml 中 frontend 的端口映射为 "8080:80"
```

### Q: Docker 构建很慢 / 拉不动镜像

Dockerfile 已配置国内镜像源（daocloud）。如仍慢，可在服务器配置 Docker 镜像加速：

```bash
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<EOF
{
  "registry-mirrors": ["https://docker.m.daocloud.io"]
}
EOF
sudo systemctl restart docker
```

## 七、文件清单

| 文件 | 作用 |
|------|------|
| `docker-compose.yml` | 三容器编排（postgres + backend + frontend） |

| `scripts/deploy.sh` | 一键部署脚本 |
| `scripts/init.sql` | PostgreSQL 建表 + 初始数据 |
