## 一、产品概述

### 1.1 产品定位

智航万恒测试验证管理平台（简称「平台」）是一款面向数据中心测试验证行业的**数字化管理工具**，旨在替代传统的纸质测试脚本、线下签字审批和 Excel 表格管理方式，实现测试项目全流程的**在线化、标准化、可追溯化**。

平台服务于以下核心角色：

| 角色 | 使用场景 |
|------|---------|
| **测试工程师** | 每日在线填写测试记录，上传现场照片，提交审核 |
| **项目经理** | 分配测试任务，审批测试结果，跟踪项目进度 |
| **客户** | 查看测试进度，审核确认测试报告，电子签字 |
| **管理员** | 维护脚本模板库，管理知识库，配置权限，数据导出 |

### 1.2 解决的问题

| 传统方式痛点 | 平台解决方案 |
|-------------|-------------|
| 测试脚本格式不统一，客户各异 | 统一的脚本模板库，支持按专业分类管理 |
| 纸质填写效率低，后期录入麻烦 | 在线填写，实时保存，无需二次录入 |
| 审核签字不规范，代签漏签难管控 | 多级电子签字，时间戳记录，不可篡改 |
| 项目进度不透明，人员调度困难 | 实时数据看板，人员状态一目了然 |
| 历史数据分散，查询归档困难 | 集中存储，支持多维度筛选和一键导出 |
| 客户要求导出 PDF 格式难以满足 | 一键生成 PDF，保留原始表格样式和签字区 |

### 2.1 仪表盘

仪表盘是平台的**数据中枢**，为所有用户提供全局视角的项目态势感知。

#### 2.1.1 KPI 指标卡

展示四个核心指标的当月数值及环比趋势：

| 指标 | 说明 | 趋势颜色规则 |
|------|------|------------|
| 活跃项目数 | 当前处于「测试中」状态的项目总数 | 数字越大越好（绿色⬆），越小则预警（红色⬇） |
| 已完成项目数 | 累计状态为「已完成」的项目总数 | 数字越大越好（绿色⬆） |
| IT 总产出（MW） | 所有项目 IT 输出功率之和 | 数字越大越好（绿色⬆） |
| 平均项目周期（天） | 所有已完成项目的平均测试天数 | 数字越小越好（绿色⬇），越大则预警（红色⬆） |

#### 2.1.2 项目状态分布饼图

展示所有项目的状态占比：

```
未开始  ████████░░░░░░░  25%
测试中  ████████████████████  50%
已完成  ████████████████░░░░  35%
阻塞    ████░░░░░░░░░░░░░░░  5%
```

#### 2.1.3 合同金额排行柱状图

展示合同金额 TOP5 的客户，辅助识别核心客户价值分布。

#### 2.1.4 重点关注项目进度条

用户可自行标记关注的项目，在仪表盘实时查看其完成度。

#### 2.1.5 最新动态时间轴

展示平台最新的项目进展、里程碑、问题记录，按时间倒序排列。

| 客户名称 | 全部 / 按客户下拉选择 |

| 列名 | 说明 |

| 计划交付日期 | 与客户的约定交付时间 |
| 实际交付日期 | 实际完成交付时间（完成后填写） |

| 字段 | 类型 | 必填 | 说明 |

右侧滑出的详情面板，显示项目完整信息和里程碑时间轴。

| 触发条件 | 自动状态 |
|---------|---------|
| 当前日期 ≥ 开始日期 | 未开始 → 测试中 |
| 当前日期超出结束日期 | 测试中 → 已完成 |
| 手动选择状态 | 按选择值 |

```

├──────────────────────────┤
│ 空闲                    │  ← 状态标签
│                          │
│ [电力] [高压证] [低压证]  │  ← 专业技能标签
│                          │
│ ──────────────────────── │

│   江苏太仓D17A段          │  ← 当前进行中项目
│   06-01 ~ 06-30          │  ← 项目起止时间

```

#### 2.4.2 人员状态分类

| 状态 | 状态点颜色 | 说明 |
|------|-----------|------|
| **空闲** | 绿色 #52c41a | 当前无项目安排，可分配新任务 |
| **测试中** | 粉色 #eb576c | 已有项目正在进行中 |

#### 2.4.3 分类筛选

顶部标签切换：**全部** / **空闲** / **测试中**，实时筛选显示。

#### 2.4.4 批量指派

当选择「空闲」状态人员后，可点击「批量指派」：

1. 弹出人员选择器（支持多选）
2. 选择关联项目（下拉列表）
3. 设置开始时间（日期选择）
4. 设置结束时间（日期选择）
5. 确认指派

指派后：人员状态自动变为「测试中」，开始时间和结束时间写入项目安排。

#### 2.4.5 编辑人员信息

点击卡片右上角编辑按钮，弹出编辑弹窗：

| 字段 | 说明 |
|------|------|
| 姓名 | 人员姓名 |
| 工号 | 系统唯一标识 |
| 状态 | 空闲 / 测试中 |
| 专业技能 | 多选标签（电气/暖通/弱电/消防 + 证书列表） |
| 项目时间安排 | 显示当前项目信息（测试中人员可见） |

**「转为空闲」按钮**：在项目时间安排区域底部，一键清空项目信息，状态归零。

### 2.6 资源计算器

资源计算器为项目经理提供**数据中心 IT 产出和电力资源的自动测算**功能。

#### 2.6.1 功能入口

左侧导航栏「资源计算器」菜单项。

#### 2.6.2 IT产出计算

根据机房 IT 负载规模自动测算 IT 产出：

```
输入：机柜数量 × 单机柜功率密度
输出：IT 总产出（MW）
```

#### 2.6.3 电力资源测算

根据 PUE 值和 IT 产出测算总电力需求：

```
输入：IT产出（MW）× PUE值
输出：总电力需求（MW）
```

### 2.7 测试脚本管理（第三阶段）

> ⚠️ 该模块为第三阶段开发内容，MVP 版本暂不包含。

#### 2.7.1 脚本模板库

管理所有测试脚本模板，支持按专业分类、设备类型筛选。

#### 2.7.2 字段构建器

可视化配置表单字段，支持 10 种字段类型：

| 字段图标 | 类型 | 示例 |
|---------|------|------|
| 📝 | 步骤 | 序号 + 测试描述，只读展示 |
| ◉ | 单选 | ☑合格　□不合格 |
| ☑ | 多选 | ☑电力　☑暖通　☑消防 |
| ▼ | 下拉选择 | 设备状态：正常/异常/待修 |
| T | 单行文本 | 备注文字输入 |
| ¶ | 多行文本 | 问题描述、处理记录 |
| 123 | 数字 | 电压(V)、电流(A)、功率(kW) |
| 📅 | 日期选择 | 测试日期、整改日期 |
| ⊞ | 数据表格 | 多行多列设备巡检记录网格 |
| ✍ | 手写签名 | Canvas 签字板 |
| 📷 | 图片上传 | 现场照片、整改对比图 |

#### 2.7.3 每日填写中心

- **动态表单渲染**：根据模板字段定义实时渲染填写界面
- **自动保存**：每 30 秒自动保存草稿，防止数据丢失
- **多人同时填写**：同一项目不同测试实例可被不同测试员同时填写

#### 2.7.4 审核签字台

**多级审核流程**：

```
测试员提交
    ↓
项目经理初审（✍签字 + 意见）
    ↓ 通过 / 驳回
客户终审（✍签字）
    ↓ 通过
✅ 项目完成，数据归档
```

**签字功能**：

- 点击「签字」弹出全屏 Canvas 手写板
- 签字保存为 base64 PNG 图片
- 签字区自动记录：签字人姓名 + 角色 + 时间戳
- 驳回时填写意见，打回重填

#### 2.7.5 PDF 导出中心

| 导出方式 | 说明 |
|---------|------|
| 单份导出 | 选择一个测试实例，导出一份完整 PDF |
| 批量打包 | 选择多个测试实例，导出 ZIP 包 |
| 按项目导出 | 选择某项目下所有测试数据，一次性打包 |

**PDF 样式要求**：

- 完整还原纸质表格样式（含表格线、合并单元格）
- 包含所有填写数据
- 签字区显示签字人姓名 + 时间戳 + 签名图片
- 页眉：项目名称、模板名称、填写日期
- 页脚：页码

## 三、用户操作手册

---

### 3.1 首页（仪表盘）

1. 打开平台网址，输入账号密码登录
2. 登录后自动进入仪表盘
3. 查看顶部 KPI 指标卡了解全局数据
4. 查看项目状态饼图了解项目分布
5. 查看时间轴了解最新动态

### 3.2 创建新项目

1. 左侧菜单点击「项目管理」
2. 点击右上角「新建项目」按钮
3. 填写项目基本信息（带 ✅ 必填字段）
4. 点击「确认创建」
5. 项目出现在列表顶部

### 3.3 指派测试人员

1. 左侧菜单点击「测试人员池」
2. 切换到「空闲」标签，查看可指派人员
3. 点击「批量指派」按钮
4. 勾选待指派人员（可多选）
5. 选择关联项目和起止时间
6. 点击「确认指派」
7. 人员状态自动变为「测试中」

### 3.4 上传知识库文件

1. 左侧菜单点击「测试管理制度」
2. 点击右上角「上传文件」按钮
3. 选择本地文件（支持拖拽）
4. 选择所属专业分类
5. 填写文件名称和描述
6. 点击「上传」
7. 文件出现在对应分类下

### 3.5 使用资源计算器

1. 左侧菜单点击「资源计算器」
2. 选择计算类型（IT产出 / 电力资源）
3. 输入相关参数
4. 系统自动计算并展示结果
