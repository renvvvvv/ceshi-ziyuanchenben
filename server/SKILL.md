# 数据中心测试交付前期投入资源规划 V10

## 用途

根据数据中心测试项目的基本信息，自动计算并生成前期投入资源规划报告：
- 人员配置（电气、暖通、弱电、消防、柴发）
- 负载数量（6kW/8kW 负载、集中式负载）
- 峰值同时在场人数和总人天
- 按用户提供的模板格式生成 Excel 报告

## 使用流程

### 第一步：准备输入 JSON

```json
{
  "total_mw": 21.6,
  "total_duration": 21,
  "cabinet_power": 12,
  "it_transformers": [["2.3", 6]],
  "power_transformers": [["1.3", 6]],
  "total_cabinets": 1150,
  "ac_type": "液冷"
}
```

`ac_type` 支持：液冷、水冷、双冷源、风冷、liquid、air、water、dual 等（自动归一化）

### 第二步：执行计算

```bash
python scripts/resource_plan.py -i <input.json> -o <result.json>
```

### 第三步：生成 Excel 报告

```bash
python scripts/generate_excel.py <result.json> <模板.xlsx> <output.xlsx>
```

## 核心计算逻辑

### 电气链路

| 参数 | 数值 |
|------|------|
| 标准架构 | IT 6人/台，动力 4人/台 |
| 单台测试天数 | 6天 |
| 并行数 | ceil(总台数 × 6 / 工期) |
| 实际测试工期 | ceil(总台数 / 并行数) × 6天 |

### 暖通链路（液冷类）

| 测试类型 | 计算规则 | 每组人数 |
|----------|----------|----------|
| 功能测试 | 每空调间（IT变×2），每间3人×2天 | 3人 |
| 场景压测 | 每机房（IT变×1），每机房5人×1天 | 5人 |
| 前端冷源 | 液冷/双冷源/水冷项目 3人全程 | 3人 |
| 安装检查 | ceil(总MW/10)×4人，1天 | - |

### 弱电链路

| 配置规则 | 说明 |
|----------|------|
| 主测 | 1人固定 |
| 电气记录员 | ceil(电气在场人数 / 4) |
| 暖通记录员 | 暖通总组数 |

### 消防链路

| 规则 | 说明 |
|------|------|
| 最少配置 | 1名主测 + 1名测试员 = 2人 |
| 基础 | 850机柜以内配置2人 |
| 超额 | 每增加850个机柜 +1人，上限5人 |

### 负载计算

| 负载类型 | 计算规则 |
|----------|----------|
| IT负载 | IT变台数 × 每单元配置 × 1.1冗余 |
| 动力负载 | 按最大动力变压器容量查表 |

## 模板输出数据说明

### 人员投入清单

| 序号 | 名称 | 计算逻辑 |
|------|------|----------|
| 1 | 测试经理 | 1人 × 工期 |
| 2 | 电气主测 | 1人 × 工期 |
| 3 | 柴发主测 | 1人 × 工期 |
| 4 | 暖通主测 | 1人 × 工期 |
| 5 | 消防主测 | 1人 × 工期 |
| 6 | 弱电主测 | 1人 × 工期 |
| 7 | 电气测试员 | (IT在场+动力在场) × 电气实际工期 |
| 8 | 暖通测试员 | 暖通峰值在场 × 工期 |
| 9 | 弱电测试员 | 电气记录员 × 工期 |
| 10 | 消防测试员 | 按消防逻辑 × 工期 |
| 11 | 记录员 | (柴发记录员+暖通记录员) × 工期 |

### 假负载清单

| 假负载类型 | 数量 |
|------------|------|
| 6KW | ceil(6kW总需求 × 1.1) |
| 8KW | ceil(8kW总需求 × 1.1) |
| 500KW | ceil(500kW总需求 × 1.1) |
| 300KW | ceil(300kW总需求 × 1.1) |
| 2000KW | 2台（固定配比） |
