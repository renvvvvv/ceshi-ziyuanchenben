## 一、文档定位与特色

阿里 V3.0 是**全生命周期测试验证指引**，从工艺检查 → 功能测试 → 点位测试 → 综合联调 → 环境测试 → 液冷验证，形成完整闭环。

### 阿里独有/特色内容（其他厂商没有的）
1. **巴拿马电源系统**（巴拿马变压器/整流柜/交流柜，阿里自研供电架构）
2. **液冷测试验证**（巴拿马方舱/锂电方舱/CDU/IT方舱/冷却配电方舱）
3. **磷酸铁锂电池组**测试（区别于传统铅酸）
4. **间接蒸发冷却机组**（干冷器/水源热泵/水源多联机）
5. **标准化测试方案**（V3.0 新增）
6. **第三方测试单位交付物**管理要求

## 二、测试验证基本要求

### 假负载要求
- 单机柜功率：**11~20KW**（或可组合），以设计功率为准
- 单台机架式假负载：**6KW、8KW**，每个机柜至少 **2 台**
- 支持 **240V 高压直流 + 220V 交流**双输入，4 路输入（2 直 2 交）
- 线径 **3×16mm²**，与列头柜配线匹配

### 测试机柜要求
- 尺寸（宽×深×高）：**600mm × 1200mm × 2150mm**，高度不高于 2550mm
- 每机柜配 **4 条 PDU**，每条容量 **≥63A**（A/B 两路，每路 2 个 PDU）

### 人员配置（以风冷 3.0 架构整栋楼为例）
| 角色 | 人数 | 说明 |
|------|------|------|
| 测试项目经理 | ≥1 | 整体协调 |
| 电气专家 | ≥2 | 电气系统 |
| 暖通专家 | ≥2 | 制冷系统 |
| 弱电系统测试专家 | ≥1 | BA/BMS/安防 |
| 安防消防系统测试专家 | ≥1 | 消防 |
| 测试工程师 | ≥20 | 现场执行 |
> 测试人员不得随意更换，特殊原因需提前 **1 周**申请，甲方面试不合格需调换

### 测试前置条件
1. 各设备厂家已完成开机调试并合格，具备调试报告
2. **系统水质合格**方可进行暖通功能测试
3. 配电系统已完成交接试验并提供**试验报告 + 整定值表**
4. 接维管理团队负责测试质量抽查，不合格数据需复测

## 三、电气工艺检查标准（34 项，核心数值）

### 中压系统（10kV）
| 检查项 | 标准 |
|--------|------|
| 10kV 电缆头与铜排连接处 | 每相粘贴感温片，**超过 60℃ 由白变黑** |
| 相与壳壁/母排间距 | **＞125mm**（中压柜）/ **≥20mm**（低压柜） |
| 柜体间隙 | **≤5mm**，水平垂直无歪斜 |
| 设备安装位置偏差 | **＜10mm**（与施工图纸对应） |
| 母排连接螺栓 | 扭矩合格并画紧固线，丝扣满足 **2-3 丝** |
| 带电导体电气间隙与爬电距离 | **≥20mm** |

### 变压器
- 动力变压器 / 巴拿马变压器
- 安装位置偏差 **≤10mm**
- 检查温升符合标准

### 蓄电池（铅酸阀控 / 磷酸铁锂）
| 检查项 | 标准 | 依据 |
|--------|------|------|
| 电池架排列位置偏差 | **≤10mm** | — |
| 电池架水平偏差 | 每米 **≤3mm**，全长 **≤15mm** | — |
| 电池列外侧直线偏差 | **≤3mm** | — |
| 电池间隔偏差 | **≤5mm** | — |
| 蓄电池与支架层间净距离 | **≥150mm** | GB51378-2019 |
| 绝缘胶垫 | 宜铺设 | GB51378-2019 |

### 柴油发电机
| 检查项 | 标准 |
|--------|------|
| 安装位置偏差 | **≤10mm** |
| 进排风口面积 | 每 **1000KW ≥4㎡**（进风和排风各） |
| 消音片 | 厚 **100mm**，片距 **100mm**，长度 **2.5m** |
| 储油罐通气管 | 高出地面 **≥4m**，公称直径 **≥50mm**，安装阻火器 |
| 地埋油罐供油管路 | **双路由** |
| 中性点接地电阻 | **120±1% Ω**，耐热 50A/10s |

### 列头柜与 PDU
- 垂直偏差 **≤机架高度 1‰**
- 同列列头柜缝隙偏差 **≤3mm**
- 直流列头柜霍尔传感器：小负荷时提高精度（≤开关额定值 10% 控制量程）

### 等电位与接地
- **共用接地阻值 ≤1Ω**（阿里要求，比国标 GB50174 8.4.2 更严，国标只说"按最小值"）
- 大楼综合接地电阻测量并记录

| 板式换热器 | 工艺检查 |

## 五、功能测试核心要求（电气 24 项 + 暖通 44 项）

### 电气功能测试亮点
- **三相 UPS 功能测试**：整流/逆变/旁路/电池各模式切换
- **HVDC 电源功能测试**：高压直流系统
- **巴拿马电源整流柜**：阿里特色供电架构
- **铅酸/磷酸铁锂电池组**：充放电曲线、容量验证
- **高压柴油发电机功能测试**：启动/并机/供油/保护
- **10kV 假负载性能测试**：中压级大功率负载测试

### 暖通功能测试亮点
- **冷水机组功能测试**：制冷/阀门联动/保护
- **冷却塔功能测试**：风机变频/水质
- **蓄冷罐功能测试**：充冷/放冷/保冷（开式 + 闭式）
- **AHU 功能测试**：间接蒸发冷却控制逻辑
- **干冷器性能测试**：华北乙二醇防冻方案
- **各类传感器**：流量/温湿度/漏水/氢气/水压（12+ 类传感器功能测试）
