# 现场设备速查手册

> 按设备类型分组。每节包含：**关键参数 / 常见坑 / 现场命令速查**。
> 加载规则：用户问哪类设备就读哪段，不要全文加载。

## 一、通用 x86 服务器

### 关键参数

| 项 | 典型值 | 异常信号 |
|---|---|---|
| 进风温度 | 18–27°C（ASHRAE A1） | > 32°C 告警，> 35°C 降频 |
| 出风温度 | 35–50°C（视密度） | > 55°C 热点风险 |
| CPU TDP | 通用 125–350W，GPU 卡 700W+ | 长时间跑低于 PL1 = 散热/BIOS 限频 |
| PCIe 协商速率 | Gen4 x16 = 31.5 GB/s，Gen5 = 63 GB/s | 降速到 Gen3/Gen2 = 线缆/背板/固件 |
| BMC 告警等级 | Info / Warning / Critical | Critical 24h 内必须响应 |

### 常见坑

1. **BMC 时间不同步** → SEL 日志时间错位，跨设备关联失败
2. **PCIe 链路降速** → 重启/换槽位/升级背板固件
3. **CPU C-State 锁死在 C0** → 压测功耗偏高、性能反而不稳
4. **NUMA 跨节点访问** → 内存敏感型负载延迟翻倍，绑核即可验证
5. **风扇策略** → 默认"静音"模式压测时撞温度墙，会触发降频

### 现场命令速查

```bash
# BMC SEL 导出（IPMI）
ipmitool -I lanplus -H <bmc_ip> -U admin -P <pwd> sel elist > sel_$(date +%Y%m%d).log

# CPU 实时频率与温度（Linux）
watch -n 1 "cat /proc/cpuinfo | grep MHz; sensors | grep Core"

# PCIe 协商速率
lspci -vvv -s <BDF> | grep -i "link speed"

# 内存/电源错误
mcelog | tail -50   # 老内核
rasdaemon -r        # 新内核
ipmitool -I lanplus ... sel elist | grep -i "power|psu"
```

## 二、GPU / AI 服务器（H100/H200/国产卡）

### 关键参数

| 项 | 典型值 | 异常信号 |
|---|---|---|
| GPU 温度 | 显存结温 < 90°C，热点 < 105°C | 任一达阈值即降频 |
| 单卡功耗 | H100 SXM 700W，国产卡 300–700W | 长时间 < TDP = DVFS 限频/掉卡 |
| NVLink 带宽 | H100 900 GB/s（all-to-all） | 降速 = 线缆/背板/固件 |
| nvidia-smi "ECC" | 大量 DBE（Double Bit Error）= 显存退化 | DBE > 0 应立即隔离 |

### 常见坑

1. **GPU 掉卡** → PCIe link down，先查 BMC SEL + nvidia-smi -q | grep "GPU Lost"
2. **NVLink 拓扑不全** → `nvidia-smi topo -m`，确认所有卡应连尽连
3. **ECC DBE 累积** → 跑 `nvidia-smi -q -d ECC` 看 Retired Pages
4. **国产卡兼容性** → 固件/驱动/CUDA 版本三角矩阵最容易翻车
5. **IB 网卡 RoCE 丢包** → PFC/ECN 配置、PFC 风暴导致丢包

### 现场命令速查

```bash
# 看 GPU 全状态
nvidia-smi -q -d TEMPERATURE,POWER,ECC,CLOCK

# 看 NVLink 拓扑
nvidia-smi topo -m

# 跑显存压力
nvidia-smi -mig 0  # MIG 模式先关
dcgmproftester --test 1 --gpus 0

# 跑通信压力（H100）
nccl-tests all_reduce_perf -b 1G -e 8G -f 2 -g 8
```

## 三、高密度机柜与风冷

### 关键参数

| 项 | 典型值 | 异常信号 |
|---|---|---|
| 单柜功率密度 | 风冷 8–20 kW，冷板 30–50 kW，浸没 100 kW+ | 风冷超过 25 kW = 散热临界 |
| 冷通道温度 | 22–25°C（推荐 24°C） | < 18°C 结露风险，> 27°C 设备报警 |
| 冷热通道压差 | 8–15°C | 压差 < 5°C = 气流短路/盲板缺失 |
| 热点温度 | < 35°C | > 40°C 立即响应 |

### 常见坑

1. **盲板没装** → 冷热气流短路，整柜 PUE 升 0.1–0.2
2. **机柜前后门网孔堵塞** → 积灰半年 PUE 升 5–8%
3. **服务器朝向装反** → 进气变排气，单点高温
4. **冷通道封闭帘破损** → 冷气泄漏，热点抬升
5. **托盘承重不足** → 机柜变形、底部 U 位散热差

### 现场验证清单

- [ ] 冷热通道温压差 ≥ 8°C
- [ ] 每 U 位都有盲板
- [ ] 进风格栅无积灰（季度检查）
- [ ] 热点温度扫描（红外热像仪）记录在档
- [ ] 机柜门闭合严密、密封条完好

## 四、冷板式液冷

### 关键参数

| 项 | 典型值 | 异常信号 |
|---|---|---|
| 二级出水温度 | 35–45°C | > 50°C 散热能力告警 |
| 一级供水温度 | 25–35°C | 进水温度波动 ± 2°C 内 |
| 单机分液流量 | 0.5–2 L/min/板 | 偏离标称值 ± 10% 查快接头 |
| CDU 压差 | 1–3 bar | > 4 bar = 过滤器堵塞或流量过大 |
| 漏液检测 | 灵敏度 ≤ 0.5 mL/min | 误报 = 凝露；真报 = 立即隔离 |

### 常见坑

1. **冷板与 CPU/GPU 贴合不良** → TIM 厚度不均、热阻升高，需要返厂
2. **快速接头 O 圈老化** → 漏液最大来源，每 12 个月强制更换
3. **冷却液配比错误** → 乙二醇/丙二醇比例偏低导致冰点/腐蚀问题
4. **冷板内部结垢** → 流量缓慢下降，半年内 CDU 效率衰减 10–20%
5. **漏液传感器误报** → 凝露、冷凝水、传感器本身故障三种要分清

### 现场命令速查

```bash
# 流量读取（通过 BMC 或 CDU 网关 API）
curl -u admin:<pwd> http://<cdu_ip>/api/v1/fm

# 冷板进/出水温差（一般通过板载传感器）
ipmitool -I lanplus ... sdr list | grep -i "inlet|outlet|coolant"

# 漏液历史
journalctl -u leakd --since "7 days ago"
```

## 五、浸没式液冷

### 关键参数

| 项 | 典型值 | 异常信号 |
|---|---|---|
| 冷却液位 | 浸没主板 ≥ 50 mm | < 30 mm 局部暴露 = 散热恶化 |
| 槽体温度 | 40–55°C | > 60°C 设备告警 |
| 冷却液沸点 | 矿物油 > 200°C，氟化液 50–60°C | 沸点低 = 易沸腾，但传热更佳 |
| 露点控制 | 槽体表面温度 > 环境露点 + 5°C | < 0 = 结露凝水入槽风险 |

### 常见坑

1. **冷板与浸没边界** → 服务器一半冷板一半浸没的混合架构，是最容易翻车的
2. **氟化液蒸发损耗** → 每月补液 2–5%，超 8% 查密封
3. **冷凝水回滴** → 槽盖密封、配管走线最常见的二次污染源
4. **设备兼容性** → 部分风扇/电容长期浸没会失效，必须用专用型号

## 六、网络设备（交换机/网卡）

### 关键参数

| 项 | 典型值 | 异常信号 |
|---|---|---|
| 端口协商速率 | 25G/100G/200G/400G | 降速 = 光模块/DAC 线/端口 |
| 端口 CRC 错误 | < 10/min/口 | > 100 = 光模块衰减或污染 |
| 缓冲区丢包 | 一般 0 | RoCE PFC 风暴会导致 |
| 时延 | 跨 Leaf 1–3 µs | 突然翻倍 = 拥塞/路由震荡 |

### 常见坑

1. **光模块兼容性** → 第三方模块被 reject，先用 show inventory 确认
2. **PFC 风暴** → 开启 PFC 后丢包，必须配 ECN + 严格优先级队列
3. **MTU 不一致** → 巨型帧丢包，先 ping -M do -s 8972 验证
4. **LLDP/Telemetry 没开** → 故障时缺数据，验收时硬性要求打开

## 七、UPS 与配电

### 关键参数

| 项 | 典型值 | 异常信号 |
|---|---|---|
| UPS 效率 | 在线 95–97%，ECO 模式 99% | < 93% = 老化或过载 |
| 输入 THDi | < 5% | > 8% = 谐波问题，影响发电机 |
| 电池内阻 | 与新电池偏差 < 30% | > 50% = 寿命到期 |
| 旁路切换时间 | < 4 ms（在线） | > 10 ms 业务会闪断 |

### 常见坑

1. **UPS 负载率过低** → < 20% 效率反而下降，建议 30–80%
2. **电池浮充电压漂移** → 定期校准，否则容量估算失真
3. **STS 双路不同源** → 中性点漂移，烧设备
4. **PDU 分相不平衡** → 三相电流差 > 15% = 告警

## 八、监控与运维系统

### 关键指标覆盖建议

| 系统 | 必采字段 |
|---|---|
| BMC/IPMI | 进/出风温度、功耗、CPU/GPU 温度、风扇转速、PSU 状态、SEL |
| CDU | 一/二级温度、流量、压力、漏液、电导率 |
| 交换机 | 端口速率、CRC、丢包、缓存、温度 |
| UPS | 负载率、效率、电池电压/内阻、THDi |
| 环境 | 冷热通道温压差、露点、颗粒物 |

### 常见坑

1. **采样频率过低** → 1 分钟一次根本看不到 PUE 瞬时抖动
2. **时间不同步** → 跨设备关联失败，全场必须 NTP/PTP
3. **指标命名不规范** → 不同厂商叫法不同，分析时一片混乱
4. **告警阈值一成不变** → 没按季节/负载调整，冬天夏天告警量差 5 倍

## 九、现场必备工具清单

- 红外热像仪（FLIR/海康微影都行，0.1°C 精度起步）
- 温湿度计 + 露点仪（白盒/白镜都行）
- 手持式电功率插座（看 PDU 真实功耗）
- 光功率计 + 红光笔（光模块排查）
- USB 转 RS485/Modbus（读 CDU）
- 万用表 + 钳形电流表（配电问题）
- BMC/IPMI 笔记本（带 IPMIView、ipmitool）
- 标签机 + 扎带（标识清晰是排障效率的第一前提）
