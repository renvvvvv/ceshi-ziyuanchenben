## 二、A/B/C 三级速记（测试视角）

| 维度 | A 级（容错） | B 级（冗余） | C 级（基本） |
|---|---|---|---|
| **定位** | 国家级、金融/政务核心、互联网核心 | 企事业核心、医疗、交通、中型 IDC | 普通办公、测试、非关键业务 |
| **供配电** | 双路市电 + 2N UPS + 柴发 N+1 | 双路市电或一路+柴发 + UPS N+1 | 单路市电，可无 UPS |
| **制冷** | 双冷源、N+2/2N 空调 | N+1 空调，可单冷源 | 普通空调，无冗余 |
| **消防** | 智能火灾+管网式气体灭火 | 火灾报警+气体灭火或高效水喷淋 | 简易灭火器+烟感 |
| **可用率目标** | ≥ 99.99% | ≥ 99.5% | ≥ 95% |
| **测试时长建议** | 7×24h 满载 | 72h 满载 | 24h 满载 |

**强制条款**（GB50174-2017 第 8.4.4、13.2.1、13.2.4、13.3.1、13.4.1 条为强制性条文）：

- **8.4.4**：数据中心内所有设备的金属外壳、各类金属管道、金属线槽、建筑物金属结构**必须**进行等电位联结并接地
- **13.2.1/13.2.4/13.3.1/13.4.1**：防火、消防、安全相关条款

## 三、环境参数条款（GB50174-2017 第 5 章）

### 5.1 温度、相对湿度、含尘浓度（附录 A 摘要）

| 区域 | 开机温度 | 开机湿度 | 露点温度 | 停机温度 | 停机湿度 |
|---|---|---|---|---|---|
| **主机房** | 18°C ~ 27°C | — | 5.5°C ~ 15°C | 5°C ~ 45°C | 8% ~ 80%，露点 ≤ 27°C |
| **辅助区** | 18°C ~ 28°C | 35% ~ 75% | — | 5°C ~ 35°C | 20% ~ 80% |
| **不间断电源室** | 20°C ~ 30°C | — | — | — | — |

**含尘浓度**（5.1.2）：主机房在静态或动态条件下，**每立方米空气中粒径 ≥ 0.5μm 的悬浮粒子数应少于 17,600,000 粒**（即 ISO 8 级洁净度）。A 级宜达到 ISO 8，B/C 级按设计要求。

**温度变化率**：辅助区每小时温度变化 ≤ 5°C（GB50174 附录 A）。

### 5.2 噪声、电磁干扰、振动、静电

| 项 | 限值 |
|---|---|
| **噪声**（总控中心） | < 60 dB(A)（长期固定工作位测量） |
| **无线电骚扰** | 80MHz~1000MHz 和 1400MHz~2000MHz 频段 ≤ 130 dB(μV/m) |
| **工频磁场** | ≤ 30 A/m |
| **振动加速度** | 设备停机条件下，主机房地板表面垂直及水平向 ≤ 500 mm/s² |
| **静电电压** | 主机房和辅助区内绝缘体的静电电压绝对值 ≤ 1 kV |

### 静电防护（8.3）

- 8.3.2：防静电地板/地面的**表面电阻或体积电阻值应为 2.5×10⁴ Ω ~ 1.0×10⁹ Ω**
- 8.3.2：必须具有防火、环保、耐污耐磨性能
- 8.3.5：采用导电胶粘接时，接触面积 ≥ 20 cm²

## 四、防雷与接地条款（GB50174-2017 第 8.4）

### 8.4 等电位联结网格（核心条款）

- **网格规格**：防静电活动地板下，用截面积 ≥ **25 mm²** 的铜带或裸铜线构成**边长 0.6m ~ 3.0m 的矩形网格**
- **每台机柜连接**：应采用**两根不同长度**的等电位联结导体就近与网格连接
- **联结方式**：根据抗扰频率与等级选 S 型、M 型或 SM 混合型

### 8.4.8 材料与最小截面积（强制性参考）

| 用途 | 材料 | 最小截面积 |
|---|---|---|
| 等电位联结带（从等电位带至接地汇集排） | 铜 | 25 mm² |
| 从机房内金属装置至等电位带 | 铜 | — |
| 从机柜至等电位联结网格 | 铜 | 6 mm² |
| 接地汇集排之间 | 铜 | — |

### 接地电阻（8.4.2）

- 保护性接地与功能性接地**宜共用一组接地装置**
- 接地电阻**应按其中最小值确定**

## 五、供配电条款（GB50174-2017 第 8.1）

### 8.1.12（关键条款）

> A 级数据中心应由**双重电源**供电，并应设置备用电源。备用电源宜采用独立于正常电源的柴油发电机组，也可采用供电网络中独立于正常电源的专用馈电线路。当正常电源发生故障时，备用电源应能承担数据中心正常运行所需的用电负荷。

### 8.1.6 / 8.1.7

- 低压配电接地形式**宜采用 TN 系统**
- 电子信息设备**宜由不间断电源系统供电**，UPS 应有自动和手动旁路装置

### 8.1.13 电子信息设备交流供电电源质量（附录 A）

| 参数 | 范围 |
|---|---|
| 稳态电压偏移范围 | -10% ~ +7% |
| 稳态频率偏移范围 | -0.5 Hz ~ +0.5 Hz |
| 电压波形失真度 | ≤ 5% |
| 允许断电持续时间 | 0 ~ 10 ms（具体由设备要求定） |

### 市电/UPS 切换时间（行业基准，源于 A 级要求）

- A 级 UPS 切换时间 ≤ **10 ms**

## 六、空调与气流（GB50174-2017 第 7 章）

### 7.3.1 气流组织

- 单台机柜发热量 > **4 kW** 的主机房，宜采用**活动地板下送风**
- 上送下回 / 下送上回 / 侧送侧回 / 冷通道封闭等多种形式并存
- 设计前应做 CFD 模拟和验证

### 7.4 关键条款

- 7.4.1：A 级冷冻水空调系统宜设置蓄冷设施
- 7.4.6：循环机组宜设置初效/中效过滤器；新风/全空气系统必须设置初效+中效
- 7.4.9：数据中心专用空调机安装应靠近主机房，留 **15%~20% 余量**

## 七、网络与布线（GB50174-2017 第 10 章）

### 10.2 主干/水平子系统

| 等级 | 线缆要求 |
|---|---|
| **A 级** | 主干/水平均应**冗余**，OM3/OM4 多模光缆或 6A 类及以上对绞电缆 |
| **B 级** | 主干子系统应冗余 |
| **C 级** | 按设计 |

- 12 芯及以上光缆主干宜采用**多芯 MPO 预连接系统**
- 存储网络布线宜采用 **MPO/MTP 预连接系统**

### 10.2.13 铜缆与电力电缆间距（强制参考）

| 敷设关系 | 最小间距 |
|---|---|
| 铜缆在金属线槽/钢管中，与电力电缆平行 | 0.3 m（最小净距） |
| 一方在金属线槽/钢管中，另一方也在 | 0.1 m |

## 八、消防条款（GB50174-2017 第 13 章）

### 13.1 灭火系统

| 等级 | 推荐灭火系统 |
|---|---|
| **A 级** | 主机房**宜**细水雾灭火（13.1.2） |
| **B/C 级** | 主机房**宜**设置气体灭火系统（13.1.3） |
| 总控中心等长期有人区 | 应设置**自动喷水灭火** |

### 13.2 防火与疏散

- 主机房与其他区域之间应采用耐火极限 ≥ 2.0h 的防火分隔
- 单罐柴油容量 ≤ 50 m³、总储量 ≤ 200 m³ 时按 GB50156、GB50160
- 数据中心疏散距离参见 GB50174 表 13.2.3-1

## 十、GB50462-2024 验收测试要点（施工及验收标准）

> GB50462-2024 自 **2024 年 9 月 1 日**起实施。第 5.2.10、5.2.11 条为强制性条文。

### 验收流程（GB50462 标准动作）

1. **自检**：施工方自检合格
2. **预验收（内部验收）**：按附录表格逐项
3. **第三方检测**（A 级强制）：由具备 CMA 资质的第三方检测机构出具报告
4. **正式验收**：建设方组织，设计/施工/集成商/监理/客户五方签字
5. **试运行**：建议 ≥ 30 天

### 必测项目（验收必含）

| 系统 | 必测项目 | 判定 |
|---|---|---|
| **环境** | 温度、相对湿度、含尘浓度、噪声 | 按 GB50174 5.1/5.2 |
| **接地** | 等电位联结、接地电阻、网格规格 | 8.4 系列条款 |
| **静电** | 表面电阻、体积电阻、静电电压 | 8.3 系列 |
| **供配电** | 电压/频率/THD、市电-UPS 切换时间 | 8.1 系列 |
| **空调** | 风量、温差、压差、洁净度、振动 | 7.4 系列 |
| **布线** | 光纤衰减、铜缆回波损耗、串扰 | 10.2 系列 |
| **消防** | 联动、报警响应、灭火剂浓度 | 13 系列 |
| **监控** | 必采字段覆盖率、告警响应时间 | 11 系列 |
| **电磁兼容** | 无线电骚扰、工频磁场 | 5.2 系列 |

### 强制性条文（GB50462-2024 第 5.2.10、5.2.11）

- 5.2.10：设备安装及验收相关强制性条款
- 5.2.11：电气安全相关强制性条款

## 十二、A 级验收 Checklist（精简版）

> 适用：A 级数据中心正式验收前 7 天预验收
>
> ✅ = 必查项 | ⚠️ = 抽查项

### 环境类

- [ ] ✅ 主机房温度 18~27°C，记录 24h 内最高/最低/平均
- [ ] ✅ 相对湿度 35%~75%（按附录 A 推荐）
- [ ] ✅ 露点温度 5.5~15°C
- [ ] ✅ 含尘浓度（0.5μm 粒径 < 17,600,000 粒/m³）
- [ ] ✅ 噪声 < 60 dB(A)（总控中心）
- [ ] ✅ 无线电骚扰 ≤ 130 dB(μV/m)
- [ ] ✅ 振动加速度 ≤ 500 mm/s²（停机状态）

### 防雷接地类

- [ ] ✅ 等电位联结网格规格：铜带 ≥ 25 mm²，网格边长 0.6~3.0m
- [ ] ✅ 每机柜两根不同长度联结线
- [ ] ✅ 接地电阻满足最小值要求
- [ ] ✅ 防静电地板表面/体积电阻 2.5×10⁴~1.0×10⁹ Ω
- [ ] ✅ 静电电压 < 1 kV

### 供配电类

- [ ] ✅ 双重电源 + 柴发（A 级强制）
- [ ] ✅ 电压偏移 -10%~+7%
- [ ] ✅ 频率偏移 ±0.5 Hz
- [ ] ✅ THD ≤ 5%
- [ ] ✅ 市电-UPS 切换 ≤ 10 ms（A 级）

### 空调类

- [ ] ✅ 双冷源冗余
- [ ] ✅ N+1 或 2N 冗余
- [ ] ✅ 单机柜 > 4 kW 时活动地板下送风
- [ ] ✅ 初效+中效过滤器齐全
- [ ] ✅ 蓄冷装置（A 级冷冻水系统）
- [ ] ✅ 空调容量预留 15%~20% 余量

### 布线类

- [ ] ✅ OM3/OM4 或 6A 类线缆
- [ ] ✅ 主干/水平均冗余
- [ ] ✅ 12 芯以上光缆 MPO 预连接
- [ ] ✅ 铜缆与电力电缆间距 ≥ 0.3m（无隔离时）

### 消防类

- [ ] ✅ 细水雾灭火系统（A 级主机房）
- [ ] ✅ 防火分隔 ≥ 2.0h
- [ ] ✅ 联动控制正常

### 监控类

- [ ] ✅ 11.2 节必采字段全覆盖
- [ ] ✅ 告警响应时间 ≤ 5 s
- [ ] ✅ 历史数据保存 ≥ 180 天（A 级建议）

### 文档类

- [ ] ✅ 测试报告 + 缺陷归零报告
- [ ] ✅ 设备清单 + 配置清单
- [ ] ✅ 应急预案
- [ ] ✅ 培训记录
- [ ] ✅ 第三方 CMA 检测报告（A 级强制）

## 十三、常见合规陷阱

1. **A 级项目未做第三方检测** — 验收不被认可，必须 CMA 报告
2. **静电地板电阻超 10⁹ Ω** — 长期使用后表面电阻会升高，验收前必须测
3. **接地电阻"测了但没记录最小值"** — 必须记录所有子系统最小值
4. **市电-UPS 切换实测 > 10 ms** — STS 选型错误或配置不当
5. **机柜只有一根等电位联结线** — 8.4.6 强制要求"两根不同长度"
6. **粒子浓度用普通尘埃仪测** — 必须用 28.3 L/min 的粒子计数器
7. **C 级项目误用 A 级标准** — 资源浪费且不必要
8. **验收清单与合同不一致** — 验收前必须三方对齐
