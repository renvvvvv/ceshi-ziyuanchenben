# 测试数据分析框架

> 加载规则：用户贴了数据/曲线/报告，要求"分析 / 看趋势 / 找出问题"时读本文件。

---

## 一、分析四步法

```
看基线 → 找异常 → 做归因 → 给优化
```

**严禁跳过"看基线"**——没有基线的异常不叫异常。

---

## 二、能效数据分析（PUE / SPUE）

### 关键指标表

| 指标 | 定义 | 健康基线 | 异常阈值 |
|---|---|---|---|
| **PUE** | 总输入 / IT 负载 | 1.3–1.5 | > 1.6 = 节能空间大 |
| **SPUE** | (总输入 - IT) / IT | 0.3–0.5 | > 0.7 = 散热低效 |
| **CUE** | 碳排放 / IT 负载 | 0.5–0.8 kgCO₂/kWh | 与电网排放因子绑定 |
| **WUE** | 水耗 / IT 负载 | 0.5–2 L/kWh | 与气候强相关 |

### 异常定位 4 维度

1. **时间维度**：哪个时段 PUE 异常？（白天/夜间/季节性）
2. **空间维度**：哪些机柜/区域贡献最大？（绘制机房热力图）
3. **负载维度**：PUE 与 IT 负载率的相关性曲线
4. **设备维度**：CDU、UPS、冷塔的子系统效率分解

### 常见归因模式

| 现象 | 第一嫌疑 | 第二嫌疑 |
|---|---|---|
| 夜间 PUE 比白天高 | 冷塔效率下降、夜间负载低导致系统低效运行 | — |
| 季节性 PUE 波动 | 湿球温度/气候 | 冷塔风机频率未联动 |
| 周末 PUE 升高 | 人员进出频繁、门没关严 | 测试机临时开启散热差 |
| 整机房 PUE 缓慢上升 | 冷塔填料堵塞、过滤器脏 | 冷却泵效率衰减 |

### 优化建议（量化目标）

- PUE 降低 0.05 = 年省电费 X 万（按 0.8 元/kWh × IT 负载 × 8760h × 0.05 算）
- 群控策略优化：冷塔风机变频 + 冷却泵变频
- 封闭冷通道：盲板补齐、通道门密封
- AI 调优：在历史数据上训练制冷预测模型

## 三、性能数据分析

### 关键指标

| 指标 | 定义 | 工具 |
|---|---|---|
| 吞吐 (Throughput) | 单位时间完成请求数 | wrk、fio、iperf3 |
| 延迟 (Latency) | 单请求时间，p50/p95/p99/p99.9 | tcprstat、histogram |
| 抖动 (Jitter) | 延迟方差 | wrk 脚本里计算 |
| QoS | 满足 SLA 请求占比 | 自定义统计 |

### 看图心法

1. **先看曲线形状**——平稳 / 抖动 / 突刺 / 周期性？
2. **再对比基线**——同型号、同批次、同负载历史值
3. **关键拐点定位**——什么时间点/什么事件引发变化
4. **关联分析**——CPU util / 内存 / 网络 / 磁盘 IO 是否同步变化

### 常见模式

| 模式 | 病因 |
|---|---|
| 延迟长尾（p99 远超 p50） | 资源争抢、GC 暂停、IO 抖动 |
| 周期性尖刺 | 定时任务、外部巡检、缓存过期 |
| 突发拥塞 | 业务潮汐、流量调度不均 |
| 持续下降 | 资源耗尽、内存泄漏、磁盘满 |

## 四、可靠性数据分析

### 关键指标

| 指标 | 定义 | 行业基准 |
|---|---|---|
| **MTBF** | 平均故障间隔 | T1 机房 ≥ 50 万小时 |
| **MTTR** | 平均恢复时间 | < 30 min |
| **可用率** | (1 - 故障时长/总时长) × 100% | ≥ 99.99% |
| **缺陷密度** | 缺陷数 / 千行代码 | 与历史对比 |

### 缺陷收敛分析

按周绘制"开放缺陷数 / 新增缺陷数 / 关闭缺陷数"三条曲线，**健康状态**应满足：

- 关闭速率 ≥ 新增速率
- P0/P1 缺陷 24h 内响应
- 连续 2 周无新增 P0/P1

### 故障归类（PARETO 模板）

| 类别 | 占比参考 |
|---|---|
| 电源类 | 25–35% |
| 散热类 | 20–30% |
| 网络类 | 15–25% |
| 软件/驱动 | 10–20% |
| 其他 | 5–10% |

## 五、温升与散热数据

### 分析要点

1. **进出风温差**：理想 8–15°C，> 20°C 散热能力接近极限
2. **热点扫描**：用热像仪每季度扫一次，红黄区域立即处理
3. **温度梯度曲线**：从进风到出风绘出温度爬升曲线，看是否线性（异常 = 局部气流短路）
4. **季节性建模**：将温度与室外湿球温度做相关性分析

### 异常模式

| 模式 | 处理 |
|---|---|
| 单 U 位温度高 | 检查该 U 位是否空（漏风）或满（堆积） |
| 同一列机柜温度高 | 末端散热差，加盲板、加顶板 |
| 整行机柜温度高 | 冷通道封闭泄漏、检查冷量分配 |

## 六、压测报告分析

### 关键章节解读顺序

1. **测试配置**——确认与需求一致（CPU 型号、内存频率、固件版本）
2. **基线对比**——是否有历史数据/友商数据可对照
3. **稳定性时长**——30 min 跑分 ≠ 24h 稳定
4. **异常事件**——跑分过程中的重启、ECC、PCIe 降速
5. **能耗/温升**——满载功耗是否符合预期，温度墙是否触发

### 常见套路

- 厂商会挑最好一次跑分报告，**必须看 5 次中位数**
- 跑分时锁频比实际场景好，**默认是不锁频的真实场景**
- 节能模式跑出来的分数不能当标称值

## 七、可视化建议

| 数据类型 | 推荐图 |
|---|---|
| PUE 时序 | 折线图（叠加湿球温度） |
| 多机柜 PUE 对比 | 柱状图 + 热力图 |
| 温度分布 | 直方图 / 箱线图 |
| 性能压测 | 折线图（吞吐 + 延迟双 Y 轴） |
| 缺陷收敛 | 堆叠柱状图 |
| 系统拓扑 | 架构图（机房/机柜/U 位） |

工具建议：Grafana（运维）、Matplotlib/Pandas（分析）、ECharts（汇报 PPT）。
