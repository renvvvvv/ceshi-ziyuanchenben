# 字节跳动数据中心项目测试管理规范 V5.0

> 来源：字节跳动 CDCO-004-FE（外部），V5.0（2025-04-11）
> 性质：**管理规范**（非技术测试脚本），侧重测试全流程管理、人员资质、质量与安全、问题分级
> 适用：字节跳动 CN 区租赁数据中心的测试验收
> 加载规则：用户问"字节测试标准/字节跳动/字节测试管理/测试红线/测试服务商资质/字节验收流程"时读本文件

---

## 一、文档定位

字节规范的核心目标是：**拉齐 CN 区数据中心测试管理标准，保障数据中心投产后的运行可靠性**。它定义的是"测试该怎么管"，而非"具体测什么参数"（参数层面依赖各厂商技术规范 + 国标）。

---

## 二、测试管理四原则（V5.0 核心新增）

| 原则 | 含义 |
|------|------|
| **质量原则** | 全面、全量测试，**不甩项**，以标准化测试手段验证并排查项目的所有风险，**100% 完成测试验证内容** |
| **安全原则** | 项目现场需满足测试条件，所有人员安全合规操作；**存在安全风险时测试暂停**，整改后继续 |
| **结果导向原则** | 测试发现问题须有明确整改结论，以数据和事实驱动决策 |
| **系统协作原则** | 测试团队提出问题并呈现数据 → 设计团队定位原因给方案 → 交付侧推动整改 → 测试团队复测验证 |

---

## 三、测试全流程（4 阶段）

| 阶段 | 负责方 | 关键动作 |
|------|--------|---------|
| **1. 机电施工阶段** | PM（交付经理） | 机电施工进度 & 质量管控 |
| **2. 测试准备阶段** | 运维 | 测试方案核心人员面试；提前 **3 周**信息同步、测试交底 |
| **3. 综合测试阶段** | PM + 运维 | 组织综合测试、问题整改 |
| **4. 接维验收阶段** | ICS、DCD/DCE、NET | 验收交付 |

### 关键时间节点
- 综合测试管理文档由**测试负责人起草**
- 测试启动前 **3-4 周**，机房供应商拟定测试团队名单
- 安装工艺检查阶段在测试启动后统一组织，**一般周期 3 天**（在标准周期 **30 天**内）
- 测试节奏：**15-20MW / 1 组人员 / 30 天内完成**，35-60MW 配 3-4 组人员

---

## 四、测试服务商资质与人员要求

### 服务商资质要求
- 具备数据中心综合测试能力
- 核心人员（项目经理 + 各专业专家）需通过**字节面试**，不合格需调换

### 核心人员能力要求（4 个专业专家）
| 角色 | 能力要求 |
|------|---------|
| **项目经理** | 现场执行负责人，负责整体进度和质量管理，组织各方完成测试验证并推动问题整改 |
| **电气专家** | 能做电气系统风险评估和现场管理，熟悉安全规范，监督指导电气测试 |
| **暖通专家** | 能做暖通系统风险评估和现场管理，监督指导暖通测试 |
| **弱电专家** | 能做弱电系统风险评估和现场管理，监督指导弱电测试 |

> 机房供应商在确定核心人员时，应不低于上述要求

---

## 五、测试服务商"红线"行为（V5.0 新增）

红线行为是指测试服务商**严禁触碰**的违规行为，触发后面临严重后果（可能取消合作资格）。虽文档未逐条列出具体红线，但核心导向是：**严禁弄虚作假、严禁甩项、严禁安全违规**。

---

## 六、问题等级定义与整改流程

### 问题分级（测试过程中）
字节对测试发现的问题进行分级管理（P0-P3 体系，类似通用缺陷管理）：
- **P0**：影响业务中断/安全风险，立即整改
- **P1**：主要功能不可用，限时整改
- **P2**：次要功能受影响，限期整改
- **P3**：优化建议，下版本处理

### 整改闭环
1. 测试团队记录问题 + 呈现测试数据
2. 设计团队定位原因 + 给出技术方案
3. 交付侧推动机房供应商整改
4. 测试团队复测验证，闭环

---

## 七、测试前置条件

机房供应商完成机房建设且具备测试条件后，同步字节交付经理，并在项目管理文档内完成测试前置条件评估。前置条件不满足时，测试不得启动。

---

## 八、现场安全管理

- 所有人员需做好个人安全防护、现场管控
- 测试环境搭建需规避现场短路等安全风险
- 存在安全风险时测试暂停

---

## 九、紧急情况测试组织管理

字节定义了两种测试组织模式：
1. **正常情况**：标准 30 天周期，按计划推进
2. **项目紧急情况**：需字节内部升级报备，启动应急测试组织模式

---

## 十、核心量化测试指标（字节 V5.0 硬性要求）

字节虽然是管理规范，但包含了大量具体的测试量化阈值：

### 质量验收硬指标
| 指标 | 要求 | 出处 |
|------|------|------|
| 测试需求完成率 | **100%** | 质量原则 |
| 高/中风险问题销项率 | **100%** | 质量原则 |
| 低风险问题销项率 | **≥90%** | 质量原则 |
| 测试人员数据复核比例 | 1h/2h 关键数据完成后**抽取≥10%复核** | 5.7.6 |
| 测试报告交付 | 综合测试完成后 **14 天内**盖章报告 | 5.11 |

### 电气测试量化标准
| 测试项 | 量化要求 | 出处 |
|--------|---------|------|
| 变压器满载 | 100%带载 **2H**（UPS主路）+ 50%带载 0.5H | 5.6 |
| 低压母联承载验证 | **1H** | 5.6 |
| UPS 满载 | 100%带载 **2H**（主路/旁路/维修旁路） | 5.6 |
| UPS 并机阶梯加载 | 10%→100% | 5.6 |
| UPS 单机超载 | **110%-1小时、120%-10分钟** | 5.6 |
| UPS 三相不平衡 | **A50%/B100%/C50%** | 5.6 |
| UPS 阶跃测试 | 0→50%、50→100%、100→50%、50→0；0→100%、100→0 | 5.6 |
| 蓄电池放电记录频次 | **5min/10min/15min** | 5.6 |
| **列头柜压测** | 设计功率 **1.2 倍** | 5.6 |
| **PDU 压测** | 设计功率 **1.5 倍** | 5.6 |
| 列头柜/PDU 超载抽测 | **20%** | 5.6 |
| 单相 PDU 满载压零线 | **1H** | 5.6 |
| 电缆/端子扫温 | 全量排查端子虚接 | 5.6 |
| 动力链路满载判定 | 负载量 **≥设计负荷 80%** 视为满载 | 5.6.8 |
| IT 负载加载 | 单机柜 A、B 路 **各 50%** | 5.6.8 |
| 外市电稳态带载 | **5 小时内**压载测试 | 5.6.8 |
| 数据记录频次 | 30/60/120min 全量；15min 只记异常温度点 | 5.6 |

### 柴油发电机测试
| 测试项 | 要求 |
|--------|------|
| 独立并行测试 | 阶梯带载、满载压测 **4h**、超载 **1h**、容性 **1h**、突加突减 |
| 带末端负荷 | 末端 IT/动力负荷由柴发带载 **1H** |

### 暖通测试
| 测试项 | 要求 |
|--------|------|
| 风冷 100% 负载率 | 开冗余 **2H** + 关冗余 **2H** |
| 机房负载突加减测试 | 模拟突发 |
| 冷机满载/半载压测 | 性能验证 |
| 液冷系统 | CDU 功能逻辑 + 压载/带载 + 风冷液冷交叉 |
| 环境温度 | **25°C±1°C** |

### 问题整改时效
| 问题等级 | 默认整改期限 | 销项周期 |
|---------|------------|---------|
| 低风险 | **3 天** | 1-2 天 |
| 中/高风险 | **4 天** | 1-2 天 |
| 总时效 | 约 **3-4 天** | — |

## 十一、测试服务商"红线"行为（5 类，V5.0 核心）

| 红线行为 | 后果 |
|---------|------|
| 1. 数据造假 | 禁止 **1 年内**参加字节自建数据中心测试招采 |
| 2. 凭印象/拍照记录数据 | 同上 |
| 3. 推诿拒不执行 | 同上 |
| 4. 人员配置不足/一岗多职/随意变动 | 同上 |
| 5. 人员配置不达标致延期 | 同上 |

> 触发红线后由 ICS 基础设施运维负责人 + ICS 负责人确认；到期后需签承诺书并评估合格方可恢复。

## 十二、人员配置标准（精确到人数）

### 一组测试团队构成（负责一个测试单元）
| 角色 | 人数 |
|------|------|
| 电气负责人 | 1 |
| 暖通负责人 | 1 |
| 弱电负责人 | 1 |
| 电气测试工程师 | 8（不含柴发） |
| 暖通测试工程师 | 4 |
| 弱电测试工程师 | 2 |
| 柴发测试工程师 | ≥2 |
| 消防测试工程师 | ≥2 |
| 随工 | 若干 |
| **合计** | **≥ 5 + 17×组数** |

### 按机房规模配置
| 机房规模/MW | 测试组数 | 备注 |
|------------|---------|------|
| ＜20 | 1 组 | — |
| 20~35 | 2 组 | ＜25MW 可适当减少每组人数 |
| 35~60 | 3~4 组 | 15-20MW/1 组，30 天内完成 |

### 核心人员经验要求
| 角色 | 经验要求 |
|------|---------|
| 项目经理 | 5 年+，≥3 个大型 ID C（≥1000 机柜）测试管理经验 |
| 电气/暖通/弱电负责人 | 3 年+，≥3 个大型 ID C 对应专业经验 |

### 服务商资质门槛
独立完成大型数据中心（**机柜≥800 架、IT 功率≥5000kW 或 合同金额≥100 万元**，满足其一）测试验证项目 **≥3 例**

## 十三、标准工期排程（day1-3）

### 标准工期（3 天/测试单元）
| 天 | 上午 | 下午 |
|----|------|------|
| **Day1** | 电气 A 路稳态带载 | 风冷空调功能 + 液冷系统压载 + 制冷单元功能报警 |
| **Day2** | 电气 B 路稳态带载 | 风冷空调压载 + 液冷系统单机功能 + 制冷单元功能报警 |
| **Day3** | UPS 瞬态测试 + 电池放电 | — |

### 紧急工期（2 天，需字节内部升级确认）
将 day1/day2 合并，电气 A/B 路带载 + UPS 瞬态/报警/功能 + 风冷功能 + 液冷压载 + 制冷报警交叉进行。

### 电气作业安全
- 电气测试**两人一组**（一人操作、一人记录兼监护）
- 安装工艺检查在测试启动后**统一组织 3 天**（整栋楼宇）

## 十、字节规范 vs 其他厂商

| 维度 | 字节 | 阿里 | 腾讯 |
|------|------|------|------|
| **文档性质** | 管理规范（流程/人员/质量） | 技术指引（工艺+功能测试全量） | 技术规范（11系统实操） |
| **技术参数** | 不涉及（依赖国标+厂商规范） | 极详细（253章节） | 详细（含具体数值） |
| **人员管理** | 最严（面试+红线+不换人） | 严（面试+1周申请） | 一般 |
| **特色** | 四原则 + 红线 + 问题分级 | 巴拿马+液冷+标准化方案 | MDC 微模块 + 谐波标准 |
| **适用场景** | 管理层/PM/质量管控 | 测试执行全流程 | 现场测试实操 |

> **三者互补**：字节管"流程怎么走"，阿里管"工艺/功能测什么"，腾讯管"具体数值判多少"
